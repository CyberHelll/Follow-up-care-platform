\# Follow-up Care Platform



A healthcare follow-up and continuity-of-care platform prototype built with \*\*React, TypeScript, Vite, and Tailwind CSS\*\*.



The project demonstrates a patient-facing healthcare experience covering appointments, follow-up consultations, medical records, consent, wallet/payment flows, emergency handling, and support/grievance workflows.



> \*\*Status:\*\* Prototype / demonstration project. Several backend-dependent features are currently simulated locally and this project is not intended for real patient, medical, or payment data.



\---



\## ✨ Features



\### 👤 Patient Portal

\- Patient onboarding and profile management

\- English/Hindi language switching

\- Consent management

\- Persistent demo state using browser storage



\### 👨‍⚕️ Doctors \& Appointments

\- Doctor profiles and specialties

\- Doctor registration/council information

\- Follow-up eligibility flow

\- Appointment slot selection

\- Upcoming, past, and cancelled appointments

\- Rescheduling and cancellation

\- Waiting-room flow

\- Simulated doctor join/no-show handling

\- Post-consultation rating flow



\### 📹 Teleconsultation

\- Simulated video consultation interface

\- Camera and microphone controls

\- Poor-bandwidth simulation

\- Record-sharing flow

\- Emergency flagging

\- Consultation notes and prescription flow



\### 📄 Medical Records

\- PDF/JPG/PNG upload interface

\- Search and record management

\- Soft-delete/recycle-bin flow

\- Restore and permanent-delete flows

\- Demo download interactions



\### 💳 Wallet

\- Wallet balance

\- Demo top-up flow

\- Appointment payment holds

\- Hold release/deduction logic

\- Transaction ledger



\### 🆘 Support \& Grievance

\- 24×7 support interface

\- Grievance ticket creation

\- Ticket history

\- Grievance officer information
